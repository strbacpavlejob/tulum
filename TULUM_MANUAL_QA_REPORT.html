02 · Navigation

Application flow map

Solid and dashed connectors show the source-defined routes and conditions. Scroll horizontally on narrow screens.

UI-confirmed surface Code-confirmed path Blocked / conditional now Dashed connector = condition or alternate route

New user → event discovery

Sign-up → Apple/Google SSO → SSO callback → onboarding (name, birthday, gender, interested-in, intent, interests, venue types, optional photos, optional bio) → map. Email on sign-up routes to sign-in in source; a usable email form was not found.

Event → RSVP → match eligibility

Map/card → event details → RSVP. If a venue requires reservation and has contact methods, contact first, then confirm. A current event ticket unlocks Matches only during its live window (with a five-minute pre-start grace period); a location permission and position within 300m are then required.

Matching → reciprocal match → chat

Eligible profiles → gender/age filters → like (subject to dynamic cap) → reciprocal likes show a match modal. The modal can create a chat and send an opening message. Inbox chats expire six hours after the match; a live associated event adds a chat location gate.

Profile → settings and support

Profile tab → edit profile fields or photos; Settings tab → theme, language, default venue, bug report, venue suggestion, logout, or delete confirmation. Changes/submissions were not saved during discovery; account deletion was not confirmed.
